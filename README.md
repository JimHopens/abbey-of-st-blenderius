# 🍇 Секретные архивы Аббатства Святого Блендерия (1243–2026)
### Интерактивный трактат: «О природе перетёртых плодов и вяжущем семени, или Анатомия порока»

> **Аудиовизуальный интерактивный одностраничник** в стиле культового веб-опыта **[Because Recollection](http://www.because-recollection.com/)**, объединяющий эстетику старых мастеров (**Paul Reid** — академическая гризайль, кьяроскуро, пергамент) и **Faceted Cinema Deco** (монументальные кубистические грани, минеральная текстура камня, золото и жженая сиена).

---

## ✦ Ключевые особенности и интерактивные механики

1. **Центральный Астролябический Диск / Винил (Because Recollection Core)**:
   - Инерционная физика вращения с реалистичным трением и скретчем.
   - Воспроизведение процедурного звука трения иглы и камня пропорционально угловой скорости.
   - Римская гравировка по концентрическому ободу: *ARCHIVUM SANCTI BLENDERII • ANNO DOMINI MCCXLIII*.

2. **8 Интерактивных глав с уникальным геймплеем**:
   - **Глава 1: Origo Fructus Libido**: Интерактивная каменная ступка — водите курсором, чтобы перетирать спелую хурму в тягучее пюре с брызгами сока и звуками давления.
   - **Глава 2: Vacuum Blenderus**: Разгон блендера до **24,000 RPM** — зажмите мышь или Пробел для раскрутки лезвий, тряски экрана и восходящего синтезированного звука турбины.
   - **Глава 3: Manus Agitatoris**: Кинетический поршневой взбиватель — дергайте мышь туда-сюда для нагрева фрикционного датчика со снопами искр и трещоткой.
   - **Глава 4: Veneratio Pelvis**: Вязкая сакральная манговая чаша — плавное вылизывание нектара с интерференцией волн и шелковистыми завихрениями.
   - **Глава 5: Thesaurus Analis Diospyros**: Тайное хранилище семян — кликайте, чтобы сбрасывать золотые косточки в подземную тьму, где они прорастают светящимися корнями Древа Познания.
   - **Глава 6: Malleus Fornacis**: Молот кузнецов и дровосеков — кликайте для сокрушительного удара многотонным пестом с ударной волной, экранотрясением и суб-басовым грохотом.
   - **Глава 7: Index Perversionis Fructuosae**: Интерактивный калькулятор инквизиции — 5 симптомов порока, живой подсчет баллов (до 260) и автоматический штамп судилища *HAERETICUS DETECTUS*.
   - **Глава 8: Magister Magnus**: Торжественный диплом посвящения в Великие Магистры Ордена Спелой Хурмы с вводом имени, выбором сана, золотым сургучом и залпом конфетти.

3. **Синтезированный процедурный звук (Web Audio API)**:
   - Не требует внешних тяжелых mp3 файлов — все звуки (гул крипты, разгон мотора, звон колоколов инквизиции, щелчки шестерен, удар наковальни, фанфары) генерируются процедурно.
   - Анимированный 8-полосный эквалайзер в верхнем HUD.
   - Кнопка выключения/включения звука `[M]`.

4. **Выдвижной Манускрипт (Codex Drawer)**:
   - Кнопка «ЧИТАТЬ ТРАКТАТ» открывает аутентичный средневековый свиток с буквицами, готическими шрифтами (Cinzel Decorative, Cormorant Garamond, Space Grotesk), цитатами и таблицей статуса реликвии.

## 🚀 Быстрый запуск локально

```bash
# Перейдите в папку проекта
cd abbey-of-st-blenderius

# Установите зависимости (если еще не установлены)
npm install

# Запустите dev-сервер
npm run dev
```

Откройте в браузере: `http://localhost:5173/`

## 🌐 Публикация на GitHub и Vercel

### 1. Публикация на GitHub

```bash
cd abbey-of-st-blenderius

# Создайте репозиторий на github.com и выполните:
git remote add origin https://github.com/ВАШ_ЛОГИН/abbey-of-st-blenderius.git
git branch -M main
git push -u origin main
```

### 2. Развертывание на Vercel

#### Вариант А: Через веб-интерфейс Vercel (Самый простой)
1. Перейдите на [vercel.com](https://vercel.com) и нажмите **Add New... -> Project**.
2. Выберите ваш репозиторий `abbey-of-st-blenderius` на GitHub.
3. Vercel автоматически определит пресет **Vite**, команду сборки `npm run build` и папку `dist`.
4. Нажмите **Deploy**. Сайт будет онлайн через 20 секунд!

#### Вариант Б: Через Vercel CLI
```bash
npm i -g vercel
vercel
```

## 🎨 Стек технологий
- **Vite 6** — молниеносный бандлер
- **HTML5 Canvas 2D Engine** — кастомная физика частиц, инерция винила, кинематика поршней
- **Web Audio API** — процедурный синтезатор монашеского дрона, колоколов, турбины и ударов
- **Canvas Confetti** — церемониальный салют посвящения в Магистры
- **CSS Grid & Flexbox** — адаптивный Because-Recollection HUD и темная гризайль-эстетика
